# Library Book Issue-Return System

## Problem Description

This project implements a simple Library Book Issue-Return System.

The system keeps track of books, their availability, book issues, and book returns.

## Increments

### Increment 1
Implement the core book data structure and add book operation.

### Increment 2
Implement book issue and return functionality.

### Increment 3
Implement input validation and library summary/report output.
